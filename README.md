# Credit Card Fraud Detection Simulator

## Description
This project is a rule-based fraud detection simulator that analyzes credit card transaction data and assigns risk scores based on spending thresholds and rapid transaction patterns.

## Features
- Transaction monitoring
- Risk scoring for high-value transactions
- Rapid transaction detection
- Per-card transaction tracking
- SQLite database storage

## Technologies Used
- Python
- SQLite
- SQL

## How to Run
1. Clone the repository
2. Run the program
